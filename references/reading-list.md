# Initial reading list

1. Box & Wilson (1951), *On the Experimental Attainment of Optimum Conditions* — original response-surface methodology.
2. Montgomery, *Design and Analysis of Experiments* — DOE, ANOVA, factorial designs, CCD.
3. NVIDIA, *CUDA C++ Best Practices Guide* — accurate timing and performance methodology.
4. Chen et al. (OSDI 2018), *TVM: An Automated End-to-End Optimizing Compiler for Deep Learning*.
5. Zheng et al. (OSDI 2020), *Ansor: Generating High-Performance Tensor Programs for Deep Learning*.
6. Schoonhoven et al. (2019), *Kernel Tuner: A search-optimizing GPU code auto-tuner*.
7. Van Werkhoven (2021), CUDA autotuning-space data with hardware performance counters.

Make a one-page note for each source: problem, design space, tuning budget, baseline, hardware, metrics, and limitation. Those notes will make the related-work section much easier to write.
